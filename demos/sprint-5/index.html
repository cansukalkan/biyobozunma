Mikroskop Bozunma Analizi Platformu

Çok aşamalı Docker mimarisi, root olmayan kullanıcı izolasyonu, statik güvenlik sertleştirmesi ve yapay zekâ tabanlı kinetik analiz sistemi tamamlandı.

🐳 Docker & Konteyner İzolasyonu

Hafif Python 3.11-slim tabanı üzerinde çok aşamalı (multi-stage) derleme ile paketlenmiştir.

  • ✓ Root-Olmayan Kullanıcı: Konteyner içi appuser (UID 10001) ile çalışır.
  • ✓ Yetki Sınırlaması: cap_drop: ALL ve no-new-privileges: true.
  • ✓ Ağ İzolasyonu: Sadece yerel 127.0.0.1:8765 bağlantısı.
  • ✓ Dahili Sağlık Denetimi: HEALTHCHECK ile anlık durum kontrolü.
docker compose up --build -d

🛡️ Güvenlik Taramaları & Sertleştirme

Platform, endüstri standardı güvenlik tarama araçlarıyla test edilip doğrulanmıştır.

  • ✓ Bandit Analizi: 0 Kritik / 0 Yüksek / 0 Orta / 0 Düşük bulgu.
  • ✓ Pip-Audit Taraması: 0 bilinen paket güvenlik zafiyeti.
  • ✓ Girdi Güvenliği: Magic byte doğrulaması, XSS & SVG engeli.
  • ✓ Timing-Safe Token: hmac.compare_digest zamanlama koruması.
bandit -r src/ && pip-audit
